# Dashboard Screenshots

This folder contains screenshots of the completed Power BI dashboard developed for the SA Public Procurement Analytics project.

## Procurement Overview

The Procurement Overview dashboard provides a high-level view of:

- Total tenders
- Total buyers
- Total awards
- Total contracts
- Tender status distribution
- Tender activity over time
- Procurement classification
- Top buyers by tender volume

![Procurement Overview](Procurement%20Overview.png)

---

## Procurement Performance

The Procurement Performance dashboard focuses on procurement efficiency and tender duration, including:

- Average tender duration
- Longest tender duration
- Shortest tender duration
- Tenders open for 7 days or less
- Percentage of tenders open for 7 days or less
- Top buyers by average tender duration
- Top buyers by tender volume
- Tender distribution by duration
- Average tender duration by procurement classification
